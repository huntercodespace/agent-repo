## [0.1.0] - 2026-09-30

本版随 pull request #12 进入 `main`（合并提交 `a930657`）。

### 新增

- 简历问答骨架：访客在网页里提问，Express 用 SSE 把 `@earendil-works/pi-agent-core` 的工具调用和正文推到浏览器。检索、四个工具（`search_resume`、`get_project_detail`、`download_resume`、`get_contact`）和示例人物林知夏的简历数据一起落地。
- 会话、消息、反馈和简历向量放在同一个 PostgreSQL 里。向量用 pgvector 的 HNSW；中文关键词用 `@node-rs/jieba` 切词后写入 `tsvector`，再与向量做 RRF（k = 60）。迁移用 node-pg-migrate。
- 按界面定稿重做聊天页：桌面侧栏、欢迎页、思维链、项目卡片、联系方式和下载卡片，主色 `#0057c2`。
- 停止生成、失败重试、重新生成、点赞和点踩、会话重命名与删除、列表搜索、骨架屏，以及连不上服务时的页内说明。点踩可用 `pnpm feedback:report` 查看。
- `CHAT_MOCK=1` 时不调用模型，用预设 SSE 看界面；发送「模拟超时」会写入一条可重试的超时回答。

### 变更

- 会话和简历向量改为同一个 Postgres，不再另放一份向量存储。`VectorStore` 只保留 `upsert`、`rebuild`、`delete`、`search`。
- 工具步骤成功后文案改为「已查阅相关经历」「已获取项目详情」「已获取简历文件」「已获取联系方式」。检索引用写在回答正文里的上标，项目卡片仍单独列出。
- 会话列表只分今天、最近 7 天、更早。昨天落在最近 7 天。
- 单次模型请求默认 90 秒（`MODEL_TIMEOUT_MS`）。超时记为这条回答的错误，可以重试。

### 修复

- 继续对话时沿用已有消息 id 再写入，评分不再因整段重插而被外键级联删掉。改评分是新插入一行，撤销是删掉该访客在这条回答上的评分行。
- 头像 SVG 以 UTF-8 保存，`aria-label` 为「林知夏」，底色 `#d9e2ff`、人形 `#0057c2`。图片加载失败时显示姓氏首字。
- 删除确认改为读取主题的 `modal.confirm`。两个字的中文按钮不再自动插空格，取消按钮底色为 `#e5eeff`。
- 第一问结束后再拉一次会话列表。列表只含已经写过消息的会话，所以要等回答落库后新会话才会出现并处于选中态。
- 没有正文的「已停止生成」不再撑满整行，此时只保留重新生成。离线页仍只提示检查网络，原始错误记到 `console.error`。
